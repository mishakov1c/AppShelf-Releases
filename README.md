# AppShelf

**AppShelf** — компактная панель быстрого запуска программ и сайтов для Windows. Группирует ярлыки, поддерживает напоминания, таймеры, погоду и пользовательские подборки — всё в одном окне.

> Этот репозиторий предназначен **только для публикации готовых версий AppShelf**. Исходный код находится в отдельном приватном репозитории. Здесь не хранятся настройки пользователей и персональные данные.

## Скачать AppShelf

**Последняя подготовленная версия: 2.18.0.** Размещение первого выпуска в этом репозитории пока не завершено.

После публикации скачать готовый файл можно будет в разделе **[Releases](https://github.com/mishakov1c/AppShelf-Releases/releases)**. Установка не требуется: загрузите `AppShelf.exe`, поместите в удобную папку и запустите.

Для обычной сборки требуется Windows с **.NET Framework 4.8**. Антивирус и Windows SmartScreen могут проверять скачанные исполняемые файлы; отсутствие предупреждения не является подтверждением их подлинности.

## Возможности

| Функция | Описание |
| --- | --- |
| Быстрый запуск | Ярлыки приложений и сайтов, группы, поиск и варианты отображения плиток |
| Напоминания | Однократные и повторяющиеся события, тихие часы, откладывание |
| Подборки | Пользовательские каталоги: игры, фильмы, рецепты, списки покупок и вишлисты |
| Погода | Прогноз с MET Norway или Open-Meteo |
| Инструменты | Сетевые проверки, таймеры, Помодоро и работа из системного трея |
| Оформление | Фоны, галерея изображений и настройки нижней панели |

## Обновления

Подготавливается функция проверки новых стабильных версий непосредственно из этого публичного репозитория. До её выпуска новые версии нужно скачивать из **[Releases](https://github.com/mishakov1c/AppShelf-Releases/releases)** вручную.

Настройки AppShelf размещаются отдельно от исполняемого файла, в `%APPDATA%\AppShelf`. Перед ручной заменой EXE закройте приложение, в том числе через системный трей. Резервные копии данных можно создавать штатными средствами AppShelf.

## Проверка файла

Для выпущенного файла `AppShelf.exe` версии 2.18.0 исходный GitHub Release содержит SHA-256:

```text
001aab18cd7535089ca751fbcee1fca2f1288cf89b43f056d27bfef55f6b7796
```

Проверить скачанный файл в PowerShell:

```powershell
Get-FileHash .\AppShelf.exe -Algorithm SHA256
```

Сравнивайте хеш только с тем релизом, из которого скачан файл. Новые версии имеют другие контрольные суммы.
